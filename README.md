<p align="center">
This is an unofficial NeoForge port of Immersive Geology for Minecraft 1.21.1.<br/>
Requires NeoForge 21.1.265 or later and Immersive Engineering 1.21.1-12.4.2-194 or later.<br/>
JEI is optional. TerraFirmaCraft integration is not included.<br/>

**This mod is in development and not all features have been implemented**

Build the `neoforge-1.21.1-uo` branch with Java 21: `sh gradlew build`.
The unofficial JAR is written to `build/libs/`. Original assets, credits and licenses are retained.
